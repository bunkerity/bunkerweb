About OCSP Stapling

OCSP stapling improves TLS handshake performance by having the server provide an OCSP response directly to clients, eliminating the need for clients to contact the OCSP responder separately.

  • Normal Mode: Strictly enforces OCSP responses for certificates with must-staple extension
  • Staple Only Mode: Prefers stapled certificates but falls back to unstapled if needed
  • Open Mode: Recovery mode - disables must-staple enforcement if experiencing issues
